# Structura media pe sectiuni

Foloseste aceasta structura pentru imaginile si fisierele media ale site-ului.
Numele folderelor sunt pastrate in engleza, fara diacritice, ca sa fie stabile in hosting.

## Imagini

- `images/hero/`
  - imagine principala pentru primul ecran
  - variante mobile/desktop pentru fundalul hero

- `images/quick-actions/`
  - imagini sau iconite pentru Botez, Spovedanie si Donatii

- `images/liturgical-program/`
  - imagini pentru sectiunea Program liturgic
  - anunturi vizuale sau fotografii de la slujbe

- `images/about-parish/`
  - fotografii cu biserica, comunitatea si momente parohiale

- `images/foundation/`
  - imagini pentru Fundatia Noastra si proiecte comunitare

- `images/spirituality/`
  - imagini pentru Acatist, Viata Sfintei Parascheva si resurse duhovnicesti

- `images/contact-location/`
  - fotografii cu Willibrorduskerk, exterior, intrare, repere de localizare

- `images/footer-brand/`
  - logo, semn parohial, stema sau variante mici pentru footer

## Media

- `media/documents/`
  - PDF-uri, formulare, materiale pentru botez, spovedanie sau donatii

- `media/audio/`
  - inregistrari audio, pricesne, conferinte sau cateheze

- `media/video/`
  - fisiere video locale, daca nu sunt gazduite pe Facebook/YouTube

- `media/social/`
  - imagini optimizate pentru distribuire social media si Open Graph
